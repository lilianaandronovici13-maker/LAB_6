# Student Record Management System

## Project Description
This C program implements a complete student record management system using multiple abstract data types. The application allows users to store, manipulate, and retrieve student information through five distinct data structures. The system also includes file operations for persistent storage and specific functionality required by laboratory assignments.

## Student Data Structure
Each student record contains the following fields:
- Name
- Surname
- Date of birth (day, month, year)
- Gender (m/f)
- Home address
- Specialty (IS, SI, IT, ACS)
- Group number

## Implemented Data Structures

### Stack
Last-In-First-Out behavior. Supports push, pop, display, search by name/surname, search by position, delete by position, and file export.

### Simple Queue
First-In-First-Out behavior. Supports enqueue, dequeue, display, search, delete by position, and file export.

### Double-Ended Queue (Deque)
Supports insertion and deletion at both front and rear ends. All operations are O(1).

### Circular Queue
Implements a circular linked list where the last node points back to the first node. Supports enqueue, dequeue, display, and file export.

### Priority Queue
Orders students by age. Users can choose between youngest-first or oldest-first priority. Uses a comparator function that calculates exact age in total days.

## Core Functionality

### Age Calculation
The program calculates each student's age in years, months, and days based on the current system date. The calculation handles month boundaries and leap years correctly.

### Sorting
Students are sorted by age using a simple bubble sort algorithm. The sorted results are saved to output.txt with age information appended.

### File Operations
- Text mode export (.txt) - Human readable, pipe-separated format
- Binary mode export (.bin) - Raw memory dump for efficient storage
- Custom file path input for each export operation
- Read and display any text file with line numbering

### Laboratory Requirements
The program implements three specific functions:
1. Create experiment.txt by entering student data from keyboard
2. Calculate student ages, sort them, and save to output.txt
3. Prepend output.txt content to the beginning of experiment.txt without deleting existing data

## File Structure

| File | Purpose |
|------|---------|
| student_adt.h | Structure definitions and function prototypes |
| student_adt.c | Implementation of all data structure operations |
| main.c | Menu system and program entry point |
| experiment.txt | Original student data (created by user) |
| output.txt | Age-sorted student data (generated by program) |
